## כללים

1. שורת כותרת אחת, בעברית, עם מספר השלב ואבן הדרך — כדי שאפשר יהיה לעקוב אחרי התקדמות התכנית מהיסטוריית ה־git.
2. הגוף מפרט תוצרים ובדיקות — לא כוונות. מה שלא רץ — לא נכתב כאילו רץ.
3. שינוי מנוע בלי `layoutHash` diff = commit שאינו עובר סקירה (§23.3).
4. commit שמחליש בדיקה (severity/threshold/golden אוטומטי) נדחה (§23.6).
5. refactor גדול נפרד משינוי מדיניות עימוד (§23.2).
