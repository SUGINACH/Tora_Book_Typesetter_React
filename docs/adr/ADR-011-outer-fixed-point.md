# ADR-011 — מדיניות oscillation ב־TOC ונקודת השבת החוץ (outer fixed-point)

**מספר:** ADR-011 · **שלב:** 71 · **אבן דרך:** M8 · **תאריך:** 2026-11-04
**סטטוס:** מקובל
**אסמכתאות:** אפיון §11.1 (TOC מדוד; "אין pageEstimate"), §11.4, §10.3 (endnotes — משוב לנקודת השבת), §7 (הצינור: "TOC/cross-reference fixed point"), §17.3; תכנית שלב 71.

## ההקשר

תוכן העניינים הוא **תוכן שמעומד** (§11.1): שורותיו נמדדות וזורמות על עמודי
front-matter **לפני** עמודי הגוף. מכאן תלות מעגלית מובנית:

```
עמודי ה-TOC קובעים את עמוד ההתחלה הפיזי של הגוף
  ← עמודי הגוף קובעים את עמודיהם הפיזיים של הכותרות (AnchorTable; שלב 70)
    ← עמודי הכותרות קובעים את הפוליו המודפס בערכי ה-TOC (גימטריה; שלב 67)
      ← הפוליו קובע את רוחב/גובה שורות ה-TOC (הקווים נמדדים)
        ← גובה שורות ה-TOC קובע את מספר עמודי ה-TOC …
```

גם זרם ה־endnotes תלוי במספר עמודי הגוף+ה־front-matter (§10.3), והערות
הסיום מופיעות כעוגנים בטבלה. המפרט אוסר "תיקון אלמנטים" חד־פעמי אחרי
חיתוך עמוד (§7): "אם נדרש שלב חיצוני כמו TOC, הוא fixed-point מבוקר ולא
mutation חד־פעמי". כלומר: **חוזרים על העימוד עד שכל המיפויים מתייצבים** —
בלי לולאה אינסופית ובלי ערך עמוד סטייל.

## ההחלטה

1. **לולאה חיצונית מבוקרת** (`runOuterFixedPoint`, `packages/layout-engine/
   src/pagination/fixed-point.ts`): `typeset → עדכון anchors/TOC/endnotes →
   typeset חוזר` עד שווקטור המשוב זהה לקודמו (נקודת שבת). הצעד עצמו —
   פונקציה טהורה שמסופקת מבחוץ (הזרקה; המנוע אינו תלוי במדיניות, גרף §5).

2. **וקטור משוב בסדר עדכון קבוע ותלות מתועדת** (§3 במודול): האותות
   `endnote-mapping` ← `anchor-mapping` ← `toc-mapping`, כולם hash קנוני
   64 הקס של מיפוי מהתוצאה בפועל:
   - `endnote-mapping` — `layoutEndnoteFlow(...).mappingHash` (מוזן
     `bodyPageCount = front-matter + עמודי גוף`; שלב 55)
   - `anchor-mapping` — `anchorMappingHash(AnchorTable)` (כותרות מהמסלול,
     מוזזות ב־front-matter; הערות מ־`anchorReport`; שלב 70)
   - `toc-mapping` — `layoutTocFlow(...).mappingHash` (הצבות שורות ה־TOC; שלב 70)
   שינוי בעמוד אחד של עוגן/הערה/שורת TOC משנה את הווקטור. הסדר חלק
   מהחוזה — סריקתי היסטוריה משווה וקטורים שנבנו תמיד באותו סדר.

3. **זיהוי מחזור (oscillation)** — היסטוריית וקטורים לפי איטרציה: וקטור
   שנראה שוב (ושונה מהקודם לו — אחרת זו התייצבות) ⇒ מחזור מזוהה עם
   **אורך** ו**איטרציית פתיחה**; הריצה נעצרת מיד — לא ממשיכים "לראות אם
   זה יעבור לבד".

4. **תקציב קשיח** — `maxIterations` (ברירת מחדל 8, תחום 2..1000): חסם
   עליון על מספר קריאות הצעד; סחיפה מונוטונית (וקטורים חדשים לנצח)
   נעצרת בתקציב ולא בקריסת זיכרון/זמן. אין לולאה בלתי־חסומה בשום מסלו�.

5. **כשל מפורש, לא השלמה שקטה** — תוצאה שאינה מתייצבת נושאת
   `FixedPointStatusReport` (outcome, iterations, היסטוריית וקטורים,
   פרטי מחזור, `reportHash` קנוני). מסלוך release חייב לקרוא
   `requireFixedPoint` שזורק `errors.engine.TOC_FIXED_POINT_NOT_REACHED`
   (params: `iterations`, `reason`). אין החזרת תוצאה "כמעט-יציבה", אין
   ערך עמוד מנוחש במסלוך הכישלון — עומד בשער M8: "ריצה לא מתייצבת
   נכשלת מפורשות".

6. **דטרמיניזם** — הצעד טהור, ההיסטוריה וקטורית, והדוח קנוני
   (`reportHash`); אותם קלטים ⇒ אותו דוח, תמיד. מתאים לנעילת artifacts
   (שלב 74) ולביקורת הבלתי־תלויה.

## למה לא חלופות

- **תיקון חד־פעמי אחרי עימוד (mutation)** — נאסר במפרט §7; שובר את
  אינווריאנט המצב הקפוא ואת הפנקס, ומייצר עמודים שלא נבדקו.
- **pageEstimate (לנחש מספרי עמודים)** — נאסר מפורשות ב־§11.1; סותר את
  כל הבניין של שלב 70.
- **לולאה עם פסק־זמן בלבד (timeout)** — אי־דטרמיניסטי (תלוי שעון); המפרט
  אוסר שעון במנוע. התקציב וזיהוי המחזור דטרמיניסטיים לחלוטין.
- **כישלון מיידי בכל שינוי מיפוי** — היה הורג מסמכים תקינים: שינוי
  מספור חד־פעמי (ה־TOC הוסיף עמוד) הוא המקרה הנפוץ והוא מתכנס באיטרציה
  הבאה; רק מחזור/סחיפה אמיתיים הם כישלון.

## השלכות

- מספר האיטרציות הצפוי בפועל: 2–3 (שינוי גודל TOC חד־פעמי); התקציב 8
  נותן שוליים למסמכים ארוכים עם TOC רב־עמודי מבלי לפגוע בביצועים.
- ה־rollback של M8 ("ביטול מסלוך `next` למסמכים עם TOC רק אם נרשם
  במפורש") נשען על הדוח: נרשום כשהלולאה רצה, ואין מסלוך עימוד שמסתיר
  אותה.
- הדוח וה־`reportHash` נכנסים ל־artifacts של הרצות ה־CLI (שלב 74–75)
  כדי שכל release יוכל להוכיח התייצבות.
- שינוי סדר האותות או הרכבם הוא שינוי חוזה: הווקטור משתנה, וכל
  ההשוואות/הנעילות מתעדכנות במפורש (אין תאימות לאחור שקטה).
